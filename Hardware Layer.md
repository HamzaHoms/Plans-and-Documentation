1. STM32F405RGT6 (C15742) : This is the script controller, 1Mb of flash is enough for any code that will be uploaded to it, 168MHz max clock Although I will be using an external oscillator for this, for extra accuracy and stability. And 196kb of ram, more than enough for loading the backends of FatFS, the LUA interpreter, and FreeRTOS, all at once, while also allowing multi-kb LUA scripts to be loaded into memory and ran. All with enough headroom left to implement a bulk data transfer later on if needed.   
2. STM32G070KB (C529339): This is the router controller, 128kb of flash more than enough for the network routing logic code. 36kb of ram, enough for HAL data, book-keeping on the packets, and keeping packet queues, however it may struggle if a large density of packets starts flowing through the network, highly unlikely considering the low datarate of LoRa even at SF7. Up to 64MHz clock, which is plenty fast for the managed flood-fill routing logic and deduplication. 
3. 24LC512 EEPROM (C52088) : This is the scri pt storage EEPROM, 64kb of memory providing more than enough to store 4-5 large scripts or 12-15 small and simple scripts. Pairing this with FatFS will make it even easier to read and write to the memory. It will be hooked up to both MCUs, but it will mainly be written to by the router controller, and read from by the script controller, to keep the script upload pipeline as short as possible.
4. SX1278 (C67678) : This will be the main link to the rest of the network, it will be controlled by the network controller MCU and have everything go through that. It will be connected to an impedance matching network and an antenna connector, with a discrete antenna at the end. Do not forget to use the DIO pins for important IRQs.
5. BSN20BKR Isolation Mosfets (C118033) : 4x N-channel mosfets, with 2 for each I2C line work to isolate the script controller from the rest of the bus that connects to the EEPROM and network controller, this allows the network controller to cleanly reflash or edit the EEPROM's contents in the case of a bad script being uploaded and bricking the script controller. Each of the two mosfets are arranged in a back-to-back common source configuration which allows them to completely snuff out any current in both directions when they are pulled low.
6. X322516MLB4SI Crystal (C13738) : 1x 16MHz crystals for high precision clock for the script MCU.
7. X322532MMB4SI Crystal (C113671) : 1x 32MHz crystal for the SX1278's Oscillator 
8. PE4259-63 Switch (C470892) : An RF signal switch with 2 ports and a common port to switch between the TX and RX links to the antenna port.
9. BWSMA-KWE-Z001 Connector (C496551) : 50ohm RF connector for the antenna.
10. AP2112K-3.3TRG1 (C23380830) : A 3v3 LDO, low noise but extra filtering will have to be done to the 3v3 line that's feeding the RF section to prevent noise on the RF lines. It will feed the circuit from the USB port's 5v. If USB is not connected there is a dedicated 3v3 input
11. PCB : A 4-layer standard FR-4 PCB with the commonly used Signal-Ground-Power-Signal Stackup, Size to be determined during the PCB layout design.
