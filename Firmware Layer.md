1. Communication Protocol Drivers : Abstraction drivers built on STM32's HAL to control the flow of data throw the main protocols used by both MCUs. A UART driver capable of two-way TXRX of an arbitrary number of bytes, using DMA and idle-line detect to keep the main loops going. A simple SPI driver for sending and receiving bytes and commands for communication between the network controller and the SX1278. A USB driver for communication between the script controller and a USB host, the script controller will act as a peripheral device, not a host.
2. Data-Stream Driver : A driver that arbitrates communication between the script controller and the network controller, and the script controller and end-device through UART or USB. This will be a higher level abstraction of the Communication Protocol Drivers to simplify the UART, USB, and SPI drivers into Send and Receive that automatically use whichever port is active. This driver will be the interface that is exposed to the end-user.
